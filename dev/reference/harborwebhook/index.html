    HarborWebhook¶

    HarborWebhook manages a webhook policy in a Harbor project.

    API version harbor.oreonit.com/v1alpha1, namespaced, short name hwebhook.

    Example¶

    apiVersion: harbor.oreonit.com/v1alpha1
kind: HarborWebhook
metadata:
  name: ci-notifications
  namespace: team-payments
spec:
  connectionRef:
    name: prod-harbor
    namespace: harbor-system
  projectRef:
    name: team-payments
  name: ci-notifications
  description: Tell CI about pushes and scan results
  eventTypes:
  - PUSH_ARTIFACT
  - SCANNING_COMPLETED
  - SCANNING_FAILED
  targets:
  - type: http
    address: https://ci.example.com/hooks/harbor
    payloadFormat: CloudEvents
    # Sent as the Authorization header; the value never appears in status or events.
    authHeaderSecretRef:
      name: ci-webhook-auth
      key: authorization
---
apiVersion: v1
kind: Secret
metadata:
  name: ci-webhook-auth
  namespace: team-payments
type: Opaque
stringData:
  authorization: Bearer change-me

    Spec¶

    Field Type Required Default Description
    adoptExisting boolean adoptExisting takes over a webhook policy of the same name.
    connectionRef object yes connectionRef selects the Harbor instance.
    connectionRef.name string yes name of the HarborConnection.
    connectionRef.namespace string namespace of the HarborConnection. Defaults to the namespace of the referencing resource. A cross-namespace reference is only honoured when the connection's spec.allowedNamespaces permits it.
    deletionPolicy Retain \ Delete Delete
    description string description shown in Harbor.
    enabled boolean true enabled turns the webhook on or off. Defaults to true.
    eventTypes []string yes eventTypes Harbor notifies about, for example PUSH_ARTIFACT, PULL_ARTIFACT, DELETE_ARTIFACT, SCANNING_COMPLETED, SCANNING_FAILED, QUOTA_EXCEED, QUOTA_WARNING, REPLICATION, TAG_RETENTION.
    name string name of the webhook policy in Harbor. Defaults to metadata.name.
    projectName string projectName is the name of an existing Harbor project not managed by this operator.
    projectRef object projectRef names a HarborProject in this namespace. The resource waits until that project is Ready.
    projectRef.name string yes name of the referenced object.
    syncPeriod string syncPeriod overrides the connection's drift-correction interval.
    targets []object yes targets receive the events.
    targets[].address string yes address is the URL Harbor posts to.
    targets[].authHeaderSecretRef object authHeaderSecretRef selects a Secret key whose value Harbor sends as the Authorization header, for example "Bearer ".
    targets[].authHeaderSecretRef.key string yes key in the Secret.
    targets[].authHeaderSecretRef.name string yes name of the Secret.
    targets[].payloadFormat Default \ CloudEvents
    targets[].skipCertVerify boolean skipCertVerify disables TLS verification of the address. Not for production.
    targets[].type http \ slack http

    Status¶

    Field Type Required Default Description
    authSecretsVersion string authSecretsVersion records the resourceVersions of the auth header Secrets last sent to Harbor, so a Secret change triggers an update.
    conditions []object conditions: Ready=True when the webhook matches the spec.
    observedGeneration int64 observedGeneration is the spec generation the status reflects.
    projectID int64 projectID of the project the webhook belongs to.
    projectName string projectName of the project the webhook belongs to.
    webhookID int64 webhookID in Harbor.

    kubectl get harborwebhooks columns¶

    Column Source
    Project .status.projectName
    ID .status.webhookID
    Ready .status.conditions[?(@.type=='Ready')].status
    Age .metadata.creationTimestamp
