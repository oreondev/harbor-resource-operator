    HarborRobotAccount¶

    HarborRobotAccount manages a Harbor robot account and writes its credentials to a Secret.

    API version harbor.oreonit.com/v1alpha1, namespaced, short name hrobot.

    Example¶

    apiVersion: harbor.oreonit.com/v1alpha1
kind: HarborRobotAccount
metadata:
  name: payments-ci
  namespace: team-payments
spec:
  connectionRef:
    name: prod-harbor
    namespace: harbor-system
  name: ci
  level: project
  projectRef:
    name: team-payments
  description: CI pipeline push
  duration: 90
  permissions:
  - access:
    - { resource: repository, action: push }
    - { resource: repository, action: pull }
    - { resource: artifact, action: read }
  secret:
    name: payments-ci-regcred
    type: kubernetes.io/dockerconfigjson
  rotation:
    beforeExpiry: 168h

    Spec¶

    Field Type Required Default Description
    adoptExisting boolean adoptExisting takes over a robot of the same name. Because Harbor never reveals an existing secret, adoption refreshes the secret.
    connectionRef object yes connectionRef selects the Harbor instance.
    connectionRef.name string yes name of the HarborConnection.
    connectionRef.namespace string namespace of the HarborConnection. Defaults to the namespace of the referencing resource. A cross-namespace reference is only honoured when the connection's spec.allowedNamespaces permits it.
    deletionPolicy Retain \ Delete Delete
    description string description shown in Harbor.
    disabled boolean disabled disables the robot in Harbor without deleting it.
    duration int64 -1 duration in days before the robot expires. -1 means never.
    level project \ system project
    name string name of the robot without Harbor's prefix. Defaults to metadata.name. Harbor stores it as robot$ (system) or robot$+ (project).
    permissions []object yes permissions granted to the robot. For project level robots a single entry without namespace is usual.
    permissions[].access []object yes access entries granted in the namespace.
    permissions[].access[].action string yes action such as pull, push, read, list, create, update, delete, stop.
    permissions[].access[].effect allow \ deny
    permissions[].access[].resource string yes resource such as repository, artifact, tag, scan, label, helm-chart.
    permissions[].namespace string namespace is the Harbor project name, or "*" for all projects (system level only). For project level robots this defaults to the referenced project.
    projectName string projectName is the Harbor project name for project level robots when the project is not managed by this operator.
    projectRef object projectRef names a HarborProject in this namespace. Required for project level robots unless projectName is set.
    projectRef.name string yes name of the referenced object.
    rotation object rotation controls automatic secret refresh.
    rotation.beforeExpiry string beforeExpiry refreshes the secret when the robot is this close to expiring. Only useful when duration is set.
    rotation.period string period after which the secret is refreshed regardless of expiry, for example 720h.
    secret object secret describes the Kubernetes Secret that receives the credentials.
    secret.annotations object annotations added to the Secret.
    secret.labels object labels added to the Secret.
    secret.name string name of the Secret. Defaults to "-robot".
    secret.type Opaque \ kubernetes.io/dockerconfigjson Opaque
    syncPeriod string syncPeriod overrides the connection's drift-correction interval.

    Status¶

    Field Type Required Default Description
    conditions []object conditions: Ready=True when the robot exists and the Secret is written.
    expiresAt date-time expiresAt is when the robot expires; empty when it never expires.
    lastRotation date-time lastRotation is when the secret was last generated.
    observedGeneration int64 observedGeneration is the spec generation the status reflects.
    robotID int64 robotID in Harbor.
    robotName string robotName is the full name including Harbor's prefix.
    secretRef object secretRef names the Secret holding the credentials.
    secretRef.name string yes name of the referenced object.

    kubectl get harborrobotaccounts columns¶

    Column Source
    Robot .status.robotName
    Secret .status.secretRef.name
    Expires .status.expiresAt
    Ready .status.conditions[?(@.type=='Ready')].status
    Age .metadata.creationTimestamp
