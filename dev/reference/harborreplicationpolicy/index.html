    HarborReplicationPolicy¶

    HarborReplicationPolicy manages a push or pull replication policy.

    API version harbor.oreonit.com/v1alpha1, namespaced, short name hrepl.

    Example¶

    apiVersion: harbor.oreonit.com/v1alpha1
kind: HarborReplicationPolicy
metadata:
  name: releases-to-edge
  namespace: platform
spec:
  connectionRef:
    name: prod-harbor
    namespace: harbor-system
  direction: push
  destRegistryRef:
    name: edge-eu-west
  destNamespace: payments
  filters:
  - { type: name, value: "payments/**" }
  - { type: tag, value: "v*", decoration: matches }
  trigger:
    type: scheduled
    cron: "0 0 2 * * *"
  override: true
  singleActiveReplication: true

    Spec¶

    Field Type Required Default Description
    adoptExisting boolean adoptExisting takes over a policy of the same name.
    connectionRef object yes connectionRef selects the Harbor instance.
    connectionRef.name string yes name of the HarborConnection.
    connectionRef.namespace string namespace of the HarborConnection. Defaults to the namespace of the referencing resource. A cross-namespace reference is only honoured when the connection's spec.allowedNamespaces permits it.
    copyByChunk boolean copyByChunk transfers blobs in chunks.
    deletionPolicy Retain \ Delete Delete
    description string description shown in Harbor.
    destNamespace string destNamespace is the target project or namespace. Empty keeps the source path.
    destNamespaceReplaceCount int32 -1 destNamespaceReplaceCount is how many leading path components destNamespace replaces. -1 is Harbor's legacy mode.
    destRegistryRef object destRegistryRef names the HarborRegistry to push to. Required for push.
    destRegistryRef.name string yes name of the referenced object.
    direction push \ pull yes
    enabled boolean true enabled enables the policy.
    executeOnCreate boolean executeOnCreate starts one execution right after the policy is created.
    filters []object filters are managed in full.
    filters[].decoration matches \ excludes
    filters[].type name \ tag \ label \ resource
    filters[].value string yes value is a glob for name and tag (for example "payments/**", "v*"), a label name for label, and image or chart for resource.
    name string name of the policy in Harbor. Defaults to metadata.name.
    override boolean true override replaces artifacts that already exist at the destination.
    replicateDeletion boolean replicateDeletion propagates deletions.
    singleActiveReplication boolean singleActiveReplication skips a run while the previous one is still active.
    speedKBps int32 speedKBps limits bandwidth. 0 means unlimited.
    srcRegistryRef object srcRegistryRef names the HarborRegistry to pull from. Required for pull.
    srcRegistryRef.name string yes name of the referenced object.
    syncPeriod string syncPeriod overrides the connection's drift-correction interval.
    trigger object trigger says when the policy runs.
    trigger.cron string cron expression (Harbor uses six fields with seconds) for type scheduled.
    trigger.type manual \ scheduled \ event_based

    Status¶

    Field Type Required Default Description
    conditions []object conditions: Ready=True when the policy exists and matches the spec.
    executedOnCreate boolean executedOnCreate records that the executeOnCreate run was started.
    lastExecution object lastExecution mirrors the most recent execution in Harbor.
    lastExecution.endTime date-time endTime of the execution.
    lastExecution.id int64 yes id of the execution.
    lastExecution.startTime date-time startTime of the execution.
    lastExecution.status string status such as Succeed, Failed, InProgress, Stopped.
    observedGeneration int64 observedGeneration is the spec generation the status reflects.
    policyID int64 policyID in Harbor.

    kubectl get harborreplicationpolicies columns¶

    Column Source
    Direction .spec.direction
    Trigger .spec.trigger.type
    Last run .status.lastExecution.status
    Ready .status.conditions[?(@.type=='Ready')].status
    Age .metadata.creationTimestamp
